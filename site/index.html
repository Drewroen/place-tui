play in your terminal

This page is the live map. To move around and paint, install the place client and run it in your terminal. 

cargo install place-tui

Then run place. It connects to the public server by default.

  • ↑↓←→ / wasd — move
  • space — open the color picker
  • enter — choose the highlighted color
  • q / esc — quit

Once you choose a brush, every tile you step onto is painted with it.
